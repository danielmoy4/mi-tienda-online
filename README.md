# 🛍️ Mi Tienda Online - Etapa 3

En esta etapa del proyecto se implementaron mejoras visuales, organización de componentes y funcionalidades relacionadas con la experiencia del usuario.

## ✅ Funcionalidades implementadas

- ✅ **Navbar dinámico**: creado con JavaScript para inyectar el mismo menú de navegación en todas las páginas.
- ✅ **Redirección** automática al inicio (`index.html`) después del registro exitoso.
- ✅ **Visualización de usuario activo**: muestra el nombre del usuario logueado en el navbar.
- ✅ **Botón de cerrar sesión** funcional.
- ✅ **Página de perfil** con estructura base (sin estilos definitivos).
- ✅ **Optimización del código HTML y organización de carpetas**.

## 📁 Archivos relevantes

- `js/navbar-data.js`: contiene la estructura del menú.
- `js/navbar.js`: inyecta dinámicamente el navbar en cada página.
- `cabecera.html`: archivo parcial usado como base para el navbar.
- `profile.html`: nueva página de perfil.
- `estilos.css`: hoja de estilos principal.
